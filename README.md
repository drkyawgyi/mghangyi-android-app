# MGHANGYI Android WebView App

This project wraps `https://mghangyi.com/` in an Android WebView.

## GitHub build
1. Create a GitHub repository.
2. Upload all files from this project.
3. Push to the `main` branch.
4. Open **Actions**.
5. Select **Build APK**.
6. Run the workflow if needed.
7. Download the `mghangyi-debug-apk` artifact.

## Notes
- The PHP/MySQL website remains on its existing server.
- GitHub is only used for source code and APK build automation.
- Change the package name, app label, and icon before publishing/distributing.
- This starter build is a debug APK; production release signing should be configured separately.
